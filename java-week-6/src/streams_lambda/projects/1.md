# Project: In-Memory User Management System

## Goal

Build a small **user management system** using plain Java.

This project is designed to help you practice:

- classes and objects
- lists
- generics
- streams
- lambdas
- simple service/repository structure

Later, when we move to Spring Boot, you will see very similar ideas again:

- `Repository`
- `Service`
- filtering data
- mapping data

> For now, we will do everything manually in plain Java.

---

## Project Idea

Create an application that stores users **in memory** and allows simple operations such as:

- saving users
- listing all users
- finding active users
- finding users older than a given age
- sorting users by age
- extracting user emails

---

## Required Classes

Create the following classes.

### 1. `User`

Represents one user in the system.

Fields:

- `int id`
- `String name`
- `String email`
- `int age`
- `boolean active`

Requirements:

- constructor
- getters
- `toString()`

### 2. `Repository<T>`

A simple generic repository.

Responsibilities:

- store items in a `List<T>`
- add new items
- return all items

Methods:

```java
void save(T item);
List<T> findAll();
```

### 3. `UserService`

This class contains business logic.

It should receive a `Repository<User>` in its constructor. (Dependency injection)

Example:

```java
public UserService(Repository<User> repository)
```

Implement the following methods:

```java
List<User> findActiveUsers();
List<User> findUsersOlderThan(int age);
List<User> sortByAge();
List<String> getAllEmails();
```

Use streams where possible.

### 4. `Main`

Create and run the application.

In `main()`:

- create a `Repository<User>`
- create a `UserService`
- save at least 5 users
- print:
	- all users
	- active users
	- users older than 30
	- users sorted by age
	- all emails

## Hints

### Repository storage

Inside `Repository<T>` you will probably need:

```java
private List<T> items = new ArrayList<>();
```

### Active users

```java
.filter(user -> user.isActive())
```

### Users older than a given age

```java
.filter(user -> user.getAge() > age)
```

### Emails

```java
.map(User::getEmail)
```

### Sorting

```java
.sorted(Comparator.comparing(User::getAge))
```

## Why This Project Matters

This project introduces ideas that are common in real backend applications:

- storing data
- separating data access from business logic
- using streams for filtering and mapping
- using generics for reusable code

Later in Spring Boot, many of these ideas will appear again in a more advanced form.
